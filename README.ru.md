# desk — темы рабочего пространства для KDE Plasma 6

[English version](README.md)

`desk` сохраняет весь рабочий стол Plasma как тему с именем и переключает темы в один клик.
В тему входят панели с виджетами, виджеты на рабочем столе и обои на каждом мониторе (картинки,
видео, любой плагин обоев). А ещё цветовая схема, стиль Plasma, иконки, курсор, шрифты, рамки
окон, тема Kvantum, вид Alt+Tab, экран блокировки и другое.

Можно собрать стол «под Windows 11», аниме-стол с видеообоями и строгий рабочий, сохранить
каждый и переключаться между ними виджетом на панели.

## Чем не подошли Konsave и глобальные темы

- **Глобальная тема** (Look and Feel) меняет только часть оформления. Если применить её вместе
  с раскладкой рабочего стола, панели сбросятся к раскладке автора темы, а ваши виджеты и их
  настройки пропадут.
- **Konsave** копирует файлы настроек при запущенном `plasmashell`. Plasma при выходе
  перезаписывает свои файлы, и панели с виджетами часто возвращаются не такими, как были, или
  не возвращаются вовсе.

`desk` останавливает оболочку Plasma, записывает файлы, запускает её снова и сообщает открытым
приложениям и KWin о смене оформления. Тема меняется сразу, выходить из сеанса не нужно.
Кроме того, `desk`:

- **сливает файлы, а не заменяет.** Из `kdeglobals` или `kwinrc` берутся только группы и ключи,
  которые относятся к оформлению. Горячие клавиши, мышь, мониторы, тайлинг, язык и настройки
  приложений никогда не трогаются.
- **хранит обои вместе с темой.** Каждая картинка или видео из темы копируется один раз (по
  содержимому, без дублей) в `~/.local/share/desk-themes/.assets/`. Тема продолжит работать,
  даже если исходный файл перенесли или удалили. Неиспользуемые копии удаляются.
- **делает резервные копии.** Перед каждым переключением текущее состояние сохраняется
  (хранятся последние 5). `desk restore` возвращает его.
- **замечает несохранённые изменения.** Если после применения темы вы что-то поменяли на столе,
  перед переключением окно выбора предложит сохранить эти изменения.
- **предупреждает о недостающем.** Перечисляет виджеты, плагины обоев, наборы иконок, курсоры,
  цветовые схемы и глобальные темы, которые нужны теме, но не установлены.

## Что входит в тему

| Что | Файлы |
|---|---|
| Панели, виджеты на столе, обои на каждом мониторе | `plasma-org.kde.plasma.desktop-appletsrc`, `plasmashellrc` |
| Стиль Plasma, заставка входа | `plasmarc`, `ksplashrc` |
| Слой «по умолчанию» глобальной темы | `~/.config/kdedefaults/` |
| Цвета, акцент, шрифты, иконки, стиль виджетов | части `kdeglobals` |
| Рамки окон, эффекты KWin, вид Alt+Tab | части `kwinrc`, `breezerc`, `auroraerc`, rc темы Aurorae, `klassyrc`, `lightlyrc`, `darklyrc` |
| Выбранная тема Kvantum | `Kvantum/kvantum.kvconfig` |
| Тема и размер курсора | часть `kcminputrc` |
| Обои и вид экрана блокировки | `[Greeter*]` из `kscreenlockerrc`, пользовательская копия оболочки рабочего стола (свой QML экрана блокировки) |
| Подписи раскладок в трее | `DisplayNames` в `kxkbrc` |
| Файловый менеджер по умолчанию | `inode/directory` в `mimeapps.list` |
| Положение KRunner (сверху или по центру) | `FreeFloating` в `krunnerrc` |

Намеренно не сохраняются: горячие клавиши, мышь и тачпад, мониторы, тайлинг, язык, питание и
настройки приложений. Сами наборы оформления (иконки, стили Plasma, виджеты) тема не копирует,
а ссылается на них по имени: устанавливайте их как обычно.

## Установка

Нужны: KDE Plasma 6, Python 3.8+, `kdialog` (окно выбора), `ffmpeg` (необязательно, для
превью в виджете на панели).

```sh
git clone https://github.com/WonderOfEnd/plasma-desk
cd plasma-desk
./install.sh
```

Скрипт кладёт `desk` в `~/.local/bin`, ставит виджет **Desktop Themes** («Темы рабочего
стола») и добавляет пункт в меню. Удалить: `./install.sh --uninstall`. Ваши темы останутся
в `~/.local/share/desk-themes`.

## Как пользоваться

1. Настройте рабочий стол как нравится и сохраните его: `desk save "Работа"` (или через пункт
   меню «Темы рабочего стола»).
2. Соберите следующий. `desk clean` сбрасывает стол к стандартной раскладке Plasma, чтобы
   начать с нуля (текущее состояние перед этим уходит в резервную копию). Потом
   `desk save "Аниме"`.
3. Переключайтесь командой `desk apply "Работа"`, в окне из меню или виджетом на панели.

```
desk                  окно выбора
desk list             список тем (* — применённая)
desk save ИМЯ         сохранить текущий стол как тему (или перезаписать)
desk apply ИМЯ        переключиться на тему
desk rm ИМЯ           удалить тему
desk mv СТАРОЕ НОВОЕ  переименовать тему
desk clean            сбросить к стандартной раскладке Plasma для новой темы
desk restore          вернуть состояние до последнего переключения
desk json             темы в JSON (для виджета на панели)
desk preview [ИМЯ…]   пересоздать превью
```

### Виджет на панели

Добавьте на панель виджет **Desktop Themes**. По клику он показывает карточку для каждой темы.
На карточке превью из обоев темы (для видеообоев это кадр из видео) и значок темы. Клик по
карточке переключает тему. Виджет также показывает, что в применённой теме есть
несохранённые изменения, и даёт их сохранить. Кнопка ⚙ открывает полное окно (новая тема,
переименование, удаление).

Свой значок темы — файл `icon.svg` (лучше белый, 24×24) в
`~/.local/share/desk-themes/<имя>/`. Своё превью — замените там `preview.jpg`. Оба файла
сохраняются при пересохранении темы.

Виджет нужно добавить на панель **в каждой** теме, из которой хотите переключаться: он часть
раскладки панели, как любой другой виджет.

### Настройки

Необязательные, в `~/.config/deskrc`:

```ini
[General]
Language=ru        # en или ru; по умолчанию по языку системы
PreviewScreen=0    # номер экрана Plasma, обои которого идут в превью
```

## Как это устроено

Тема — каталог `~/.local/share/desk-themes/<имя>/`. В нём лежат копии целых файлов
(`config/…`), относящиеся к оформлению части общих файлов (`config/<файл>.part`) и списки
файлов, которых у темы не было (`.absent`, `.absent-data`). Такие файлы при применении
удаляются, чтобы остатки другой темы не просачивались в эту.

Применение темы:

1. сохраняет текущее состояние в `.backups/`,
2. останавливает `plasma-plasmashell.service` (или `plasmashell`),
3. записывает целые файлы и вливает части в ваши текущие,
4. снова запускает оболочку,
5. применяет цветовую схему, курсор и иконки и рассылает сигналы KConfig/KGlobalSettings,
   чтобы открытые приложения, GTK-приложения (через kde-gtk-config) и KWin подхватили смену.

## Заметки

- Виджет, который применяет тему, не должен запускать `desk` своим дочерним процессом: тот
  погибнет вместе с оболочкой. Виджет из комплекта запускает его через `systemd-run --user`.
- Видео- и веб-обои дают сторонние плагины обоев. `desk` сохраняет их настройки и файлы так же,
  как любые другие обои.
- То, чего нет в таблице выше (например, звуки или экран входа SDDM), в тему пока не входит.
  Добавить файл — одна строка в `WHOLE` или `PARTIAL` в начале `desk`.
